# Privacy

This website is a set of static pages.

- It sets no cookies.
- It runs no analytics, tracking pixels or third-party scripts.
- It has no forms and collects no personal data.
- Fonts and images are served from this site, so your browser talks to no other servers while you read it.

The server that hosts these pages may keep standard access logs (IP address, time, page and browser) for security and troubleshooting. They are not shared or used to profile visitors.

The Nebla panel you install yourself runs on your own hardware. Nothing in it reports back to this site.
