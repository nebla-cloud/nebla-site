# Nebla docs

Nebla is an open-source cloud console for Proxmox VE. It gives the people who use your Proxmox projects, servers, SSH keys, volumes, firewalls and API tokens, with a web panel, a CLI and a REST API on top. It runs as one container next to Postgres and talks to Proxmox only through its API.

## How it fits together

- **Locations** are your Proxmox clusters or standalone nodes. Nebla connects to each with an API token.
- **Images**, **server types** and **IP pools** are what a panel admin offers: operating systems, sizes and addresses.
- **Projects** hold servers, volumes, firewalls, SSH keys and API tokens, and have members with roles and a quota.
- **Servers** are Proxmox VMs that Nebla clones from an image, sizes from a type and addresses from a pool. Nebla picks the node, VM ID and storage.
- **Actions** track every change in the background, so the panel, the CLI and scripts can follow it to the end.

## Get started

1. [Install](/docs/install) Nebla with Docker Compose and create the first admin account.
2. [Connect Proxmox](/docs/proxmox) with the one-line setup command.
3. [Set up the panel](/docs/admin): turn on OS images, add server types and an IP pool.
4. Create a project and your first [server](/docs/servers).

## Use Nebla

- [Projects and access](/docs/projects): members, roles, invites, SSH keys, API tokens, passkeys and two-factor login.
- [Servers](/docs/servers): create, power, console, graphs, rebuild, resize and delete.
- [Volumes](/docs/volumes): extra disks you attach, grow and move between servers.
- [Firewalls](/docs/firewalls): inbound and outbound rules for servers, applied directly or by label.

## Reference

The repository has deeper references, such as the [Proxmox setup reference](https://github.com/nebla-cloud/nebla/blob/main/docs/proxmox-setup.md) with every privilege explained and the [OpenAPI spec](https://github.com/nebla-cloud/nebla/blob/main/api/openapi.yaml).

## Requirements

- Proxmox VE 8 or 9. Built-in OS images need 8.4 or later.
- A Linux machine with Docker Compose that reaches the Proxmox API on port 8006.
- For passkeys, the panel on https with a domain name.
